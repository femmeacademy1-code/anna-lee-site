# אתר אנה לי מילשטיין

אתר בעברית (RTL) עם מערכת לידים, מאמרים וממשק ניהול. בנוי בלי תלויות חיצוניות: Python 3 עם SQLite, ו-JavaScript רגיל.

## הפעלה מקומית

```bash
cd anna-site
python3 build.py                  # מייצר את עמודי האתר בתיקייה site/
export ADMIN_PASSWORD='סיסמה-ארוכה-ורק-שלך'
python3 server.py                 # מפעיל את השרת על http://127.0.0.1:8000
```

- האתר הציבורי: http://127.0.0.1:8000
- ניהול (פניות, מאמרים): http://127.0.0.1:8000/admin
  שם המשתמש ברירת מחדל: admin. אפשר לשנות עם המשתנה ADMIN_USER.
- בלי ADMIN_PASSWORD אזור הניהול נסגר לחלוטין.

## קבצים

| קובץ | תפקיד |
|---|---|
| config.json | פרטי העסק: טלפון, וואטסאפ, מייל, מחירים, משכים, כתובת דומיין |
| products.json | סדנאות, קורסים וכלים חינמיים. שינוי כאן ואז build.py |
| build.py | מייצר את העמודים הסטטיים לפי הבריף |
| server.py | שרת: עמודים, API, לידים, מאמרים, ייצוא CSV, ניהול |
| static/site.css | עיצוב (צבעי המותג, RTL, נייד-ראשון) |
| static/app.js | תפריט נייד, ולידציה ושליחת טפסים, סינון וחיפוש מאמרים |
| data/site.db | מסד הנתונים (נוצר אוטומטית). לא לשתף ולא להעלות ל-Git |

## מה מנוהל איפה

- **פניות ולידים:** נשמרות במסד. בממשק הניהול אפשר לסנן לפי סטטוס, לשנות סטטוס, להוסיף הערה פנימית, ולייצא ל-CSV שנפתח באקסל בעברית.
- **הסכמה לתוכן שיווקי:** תיבה נפרדת שלא מסומנת מראש. הפנייה עצמה לא נחשבת הסכמה לדיוור.
- **מאמרים:** נוצרים ומתפרסמים מממשק הניהול, כולל כתובת, כותרת SEO, תיאור מטא, תמונה וטקסט חלופי, קטגוריה, מקורות, ומסומנים כמומלצים לעמוד הבית. מאמר שלא מסומן כמפורסם לא מופיע באתר.
- **טקסטים של העמודים, מחירים ופרטי קשר:** מתעדכנים ב-build.py או ב-config.json, ואז מריצים `python3 build.py`.

## פרטים שחסרים לפני פרסום

ראי את `config.json`. השדות הריקים (טלפון, וואטסאפ, מייל, כתובת קליניקה) לא מוצגים באתר עד שימולאו. לא הוספתי מחירים שלא נמסרו: מחיר סדנה, קורס, ומפגש בודד בריברסינג.

## לפני העלייה לאוויר

1. לקבוע את הדומיין ב-config.json ולהפעיל `draft: false`. אז ייווצרו sitemap ו-robots, והאתר ייכנס לאינדקס.
2. לאשר מדיניות פרטיות והצהרת נגישות אצל יועץ מתאים, ולהשלים את תקופת השמירה.
3. לבצע בדיקת נגישות מקצועית.
4. להריץ את האתר מאחורי HTTPS בלבד, ולהעביר את השרת מאחורי שרת אינטרנט (reverse proxy).
5. לוודא שלא נשלח מידע רגיש לכלי מדידה. טרם חוברו כלי מדידה.

## מה עדיין לא מחובר

- שליחה אוטומטית של הכלים החינמיים במייל: דורשת ספק דיוור או SMTP. כרגע הטופס שומר את הפנייה, ואין מייל נשלח.
- חיבור למערכת דיוור (למשל Mailchimp או Brevo) ורשימת הסרה אוטומטית: טרם נבנו.
- עריכת טקסטים ותמונות מתוך הממשק: כרגע דרך build.py. זו הנקודה המרכזית שכדאי להחליט עליה לפני הפרסום.
- דפי נחיתה דינמיים: התשתית מוכנה בתוך products.json, אבל אין מחולל דפים בממשק הניהול.
- אנליטיקה (GA4) ואירועי המרה: לא חוברו.
- מאמרים: אין עדיין מאמרים מפורסמים. לא כתבתי תוכן מקצועי או מחקרי בשם הכותבת.

## הערות אבטחה

- סיסמת הניהול נשלחת בבסיס בסיסי (Basic Auth). בלי HTTPS היא נחשפת ברשת.
- אין הגנת CSRF בטפסי הניהול. מומלץ לשמור על הניהול מאחורי כתובת מוגנת.
- שמירת נתונים רפואיים: הטופס אוסף רק שם, פרטי קשר, סוג השירות והודעה קצרה. השאלון הרפואי של הריברסינג נשלח בנפרד.
